# 宅建士 並走ノート

宅建士（宅地建物取引士）試験の勉強に毎日並走する、ビルド不要の静的Webアプリです。

- **今日**：試験日までのカウントダウン、学習フェーズ、今日のメニュー（復習→新規問題→数値カード）、科目別正答率と目標点の比較
- **演習**：宅建業法30・権利関係25・法令上の制限22・税その他23の計100問（オリジナル4択）。間違えた問題は間隔反復で自動的に復習へ
- **条文**：頻出条文の要点・暗記用の数値・e-Gov 法令APIから取得した条文の原文
- **模試**：本試験形式（50問・2時間）とミニ模試（20問・50分）。直近の合格点で判定
- **計画**：学習計画、曜日ごとの科目テーマ、設定、学習データの書き出し／読み込み

学習データはブラウザの localStorage に保存されます。

## 構成

```
index.html / style.css / app.js
data/questions.js   # 問題データ
data/laws.js        # 条文ノート・試験情報
```

## 注意

収録問題は頻出論点をもとにしたオリジナル問題で、本試験問題の転載ではありません。本試験の過去問は[不動産適正取引推進機構の「過去の試験問題」](https://www.retio.or.jp/exam/past_ques_ans/other/)で確認してください。条文は2026年11月7日時点のe-Gov法令APIから取得しています。
